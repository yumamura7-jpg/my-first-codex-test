# 60秒動画ストーリーボード

元記事: https://supple-hack.com/?p=5
タイトル: 「179cm/75kgの減量期に入るなら、この3つのサプリで『筋力を残す土台』を作る」

## キャラクター

- 名前: サプリくん
- 見た目: カプセル型の明るい案内役
- 役割: 難しい栄養の話を「粘り・回復感・代謝」の3語で整理するナビゲーター

## 構成

| 秒数 | 内容 | 画面の要点 |
| --- | --- | --- |
| 0〜6秒 | 結論 | 179cm/75kgの減量期は3つのサプリで土台作り |
| 6〜14秒 | 課題提起 | 減量期は体重だけでなくトレーニング出力も落ちやすい |
| 14〜22秒 | クレアチン | ATP再合成を支え、重量・レップ数の粘りを狙う |
| 22〜30秒 | リンゴ酸マグネシウム | 筋肉・神経機能、翌朝の重さやこわばり対策 |
| 30〜38秒 | ビタミンB群 | 糖質・脂質・タンパク質をエネルギーへ変える代謝サポート |
| 38〜48秒 | 3つの役割整理 | クレアチン=粘り、マグネシウム=回復感、ビタミンB=代謝 |
| 48〜55秒 | 摂取ルーティン | 朝、トレ後、夜の実践しやすい流れ |
| 55〜60秒 | まとめ | 気合いだけでなく、先に土台を揃える |

## ナレーション案

減量期に入る179cm、75kgの筋トレ民へ。  
体重を落とすときに怖いのは、筋力や回復感まで落ちること。  
そこで土台にしたいのが、この3つです。  
1つ目、クレアチン。短時間・高強度の粘りを支え、最後の1〜2レップを守る相棒。毎日3〜5gを継続。  
2つ目、リンゴ酸マグネシウム。筋肉と神経、エネルギー作りを支え、翌朝の重さやこわばり対策に。食後に分けて摂るのがおすすめ。  
3つ目、ビタミンB群。食べた糖質、脂質、タンパク質をエネルギーに変える代謝の着火剤。朝から昼の食後が使いやすい。  
まとめると、クレアチンは粘り、マグネシウムは回復感、ビタミンB群は代謝。  
朝はビタミンB群とマグネシウム、トレ後はクレアチン、夜はマグネシウム。  
減量期は気合いだけで絞らず、先に筋力を残す土台を整えよう。
