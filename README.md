## 60秒動画素材

**動画リンク:** [video/supple-hack-60sec.html](video/supple-hack-60sec.html)

**ストーリーボード:** [video/storyboard.md](video/storyboard.md)

`video/supple-hack-60sec.html` は、サプリハックの記事「179cm/75kgの減量期に入るなら、この3つのサプリで『筋力を残す土台』を作る」を、キャラクター「サプリくん」付きで60秒に要約した動画風HTMLです。

ブラウザで開くと16:9のアニメーションとして再生されます。必要に応じて画面録画ツールでMP4化してください。

```bash
open video/supple-hack-60sec.html
```

構成とナレーション案は `video/storyboard.md` にまとめています。
